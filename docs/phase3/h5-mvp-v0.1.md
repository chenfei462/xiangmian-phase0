# Web/H5 MVP v0.1

第3阶段把第1阶段古籍知识库和第2阶段视觉原型整合为可体验的 Web/H5 MVP。默认继续使用 Vite + React + TypeScript，不迁移 Next.js，不做小程序、后台管理、真实服务端埋点或正式分享海报。

## MVP 闭环

1. 入口：用户进入后可选择开镜授权或手动抽卡。
2. 授权：摄像头文案明确端侧处理、单次使用、可拒绝授权。
3. 校准：开镜后进入 3 秒校准，检查模型状态、脸部质量和居中情况。
4. 动作：通过正视、眨眼、微笑、抬眉、张口、回顾、闭眼触发抽卡。
5. 抽卡：使用第1阶段 A/B 且审核通过的候选卡牌，不返回 C/D 条目。
6. 结果：展示安全标题、出处、现代释义、安全文案、行动建议和免责声明。
7. 退出：停止摄像头 track，清理本地临时会话数据。

目标体验时间为 90 秒内完成一次开镜或手动抽卡闭环。

## 隐私与合规

- 摄像头帧仅在浏览器端侧处理。
- 不上传、不保存原始图像、视频、人脸模板或身份标识。
- 不进行身份识别，不推断健康、命运、寿命、生育、婚恋刑克或敏感属性。
- 拒绝摄像头、模型失败、低质量帧或动作失败时，必须提供手动抽卡。
- 结果页必须展示免责声明，提醒用户这只是传统文化娱乐化解读。

## 验收

- `npm run validate:mvp` 验证第3阶段合同、状态机、手动兜底和安全抽卡。
- `npm test` 保证第0-3阶段合同、知识库和视觉能力不回退。
- `npm run build` 保证 H5 MVP 可打包。
- 浏览器验收需覆盖首页加载、手动抽卡闭环、结果页出处与免责声明、无控制台错误。
