# 第5阶段灰度测试反馈报告

阶段目标：用小范围真实用户测试验证 Phase 4 H5 MVP 的完成率、动作成功率、手动兜底、内容安全和分享意愿。

## 灰度批次

- 批次：`GRAY-001`
- 版本：`phase5-gray-v0.1`
- 目标样本：30-50 人
- 覆盖浏览器：Desktop Chrome、Android Chrome、iOS Safari
- 数据来源：匿名事件本地记录、人工反馈表、静态 fixture 看板
- 隐私默认：不上传原始图片、视频或人脸模板，不记录关键点数组、姓名、手机号、用户 ID 或设备指纹。

## 指标口径

- 完成率：结果页到达并完成退出或再抽流程的会话占比。
- 手动抽卡完成率：选择或进入手动模式后到达结果页的占比。
- 动作成功率：未进入 `action_timeout` 的测试会话占比。
- 结果页到达率：出现卡牌结果页的会话占比。
- 分享意愿：反馈表中选择愿意分享的占比；第5阶段不统计真实分享转化。
- 负面反馈率：反馈表中文案安全评分过低或命中文案/隐私风险标签的占比。

## 样例看板

当前静态样例用于验证 `GrayMetricsReport v0.1`：

- 完成率：75%
- 手动抽卡完成率：100%
- 动作成功率：75%
- 结果页到达率：75%
- 分享意愿：50%
- 负面反馈率：0%
- 主要失败原因：`action_timeout`

样例看板中的动作成功率低于正式 90% 门槛，因此真实灰度若出现同类数据，应进入 hold 并修复动作提示或阈值。

## 内容与风险

- 用户结果继续只允许 A/B 且审核通过卡牌。
- C/D 条目不得进入用户结果。
- 命中卡牌下线清单的 `card_id` 不得被抽中。
- 灰度期间风险文案投诉目标为 0。
