# 合规红线 v0.1

状态：产品和技术侧默认约束，最终法律结论需法务复核。

## 1. 数据处理默认值

- 摄像头帧仅在用户设备端侧处理。
- 不上传、不保存你的原始图像或视频。
- 不保存人脸模板、关键点模板或可用于识别身份的持久化生物识别数据。
- 不进行身份识别、身份比对、年龄/性别/种族/民族等敏感属性推断。
- 后台只允许匿名事件：动作完成、卡牌类别、停留时长、分享点击。
- 用户关闭摄像头后必须停止视频轨道。

## 2. 摄像头授权文案

我们将使用摄像头在你的设备上识别人脸关键点和表情动作，用于本次“观相镜”传统文化娱乐互动。默认不上传、不保存你的原始图像或视频，不进行身份识别。你可以拒绝授权并进入手动抽卡模式。继续即表示你同意本次使用摄像头进行端侧互动分析。

## 3. 输出红线

禁止输出或暗示：

- 命运、财富、职业、学业、婚恋结果的确定性结论。
- 健康、疾病、寿命、怀孕、生育能力、心理状态判断。
- 犯罪倾向、智力高低、道德优劣、种族/民族/宗教/政治倾向/性取向。
- “败相”“恶相”“贫贱”“孤寡”“克夫”“克妻”“刑克”等羞辱或歧视性标签。
- 任何可被理解为替代医疗、法律、财务、招聘、信贷、保险、教育、司法判断的建议。

## 4. 未成年人

- 产品不主动面向未成年人。
- 未成年人不得进入摄像头体验。
- 若活动现场无法确认年龄，默认提供手动抽卡和公开屏幕演示，不采集个人脸部数据。

## 5. 结果页免责声明

本结果为传统相面文化的娱乐化解读，不能作为性格、命运、健康、婚恋、职业、财务或任何重要事项的判断依据。请把它当作一张国风互动卡牌和今日行动提醒。
