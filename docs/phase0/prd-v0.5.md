# 观相镜 PRD v0.5

版本：v0.5  
阶段：第0阶段 / 立项与 Web/H5 技术预研  
首版形态：Web/H5  
默认后续架构：React + Next.js App Router + TypeScript + MediaPipe Face Landmarker Web  
当前预研原型：Vite + React + TypeScript，用于快速验证浏览器摄像头与端侧动作链路

## 1. 产品定位

观相镜是一款把传统相面文化资料转化为卡牌、动作交互和轻量行动建议的文化娱乐产品。它不提供科学化人格、命运、健康、婚恋、财务或职业判断，只通过端侧人脸关键点、表情动作和用户选择触发安全文案。

## 2. 核心人群

- 国风、传统文化、玄学娱乐兴趣用户：希望得到有出处、有仪式感、可分享的轻量互动结果。
- 文旅和展览观众：希望在 90 秒内完成一次“看镜头 - 做动作 - 抽卡 - 得到解释”的现场体验。
- 品牌活动客户：需要可定制、可传播、风险可控的互动 H5。

## 3. MVP P0

- 开镜授权与校准：进入摄像头前展示用途、端侧处理和退出方式。
- 动作触发：识别或模拟 `look_stable`、`blink`、`smile`、`brow_up`、`mouth_open`、`head_turn`。
- 古籍卡牌抽取：动作事件触发规则引擎，规则只输出 A/B 风险且审核通过的卡牌。
- 出处解释面板：展示卡牌 ID、术语、来源和风险等级。
- 免责声明：结果只作为传统文化娱乐解读。
- 手动抽卡模式：用户拒绝摄像头后仍可进入完整体验。

## 4. P1 延后

- 分享海报、高清图导出、主题牌库、运营后台、活动数据看板。
- 正式 Next.js App Router 项目化、服务端配置、部署流水线。
- 小程序、线下互动镜、直播插件。

## 5. 非目标

- 不做人脸识别、身份比对或登录绑定。
- 不保存原始图片、视频或人脸模板。
- 不推断年龄、性别、种族、民族、宗教、政治倾向、性取向、健康、疾病、寿命、生育、婚恋结论。
- 不输出“必然”“命中注定”“贵贱”“刑克”等确定性或羞辱性判断。
- 不面向未成年人开放摄像头体验。

## 6. 90 秒用户旅程

1. 进入：用户看到文化娱乐定位、无需登录、可拒绝摄像头。
2. 授权：同意后开启摄像头；拒绝后进入手动抽卡模式。
3. 开镜：浏览器本地视频流进入镜面，系统给出居中和动作提示。
4. 动作：用户微笑、抬眉、眨眼、张口或左右顾盼。
5. 抽卡：动作事件进入规则引擎，过滤风险后返回卡牌。
6. 解读：结果页展示安全文案、出处、风险等级和免责声明。
7. 退出：关闭摄像头轨道并清理本地临时状态。

## 7. 验收指标

- 用户在明亮环境下可以完成一次开镜到抽卡闭环，目标时长小于 90 秒。
- 拒绝摄像头后仍可手动抽卡。
- P0 卡牌结果必须展示出处、现代释义或行动建议、风险等级。
- 所有上线文案必须通过风险词扫描和人工审核。
- 技术预研必须能证明浏览器摄像头授权、MediaPipe 加载方案、动作事件映射和降级路径可行。
