# Phase 5 灰度测试交接包

第4阶段交接目标：进入第16-18周小范围真实用户灰度测试，验证完成率、分享率、动作成功率、负面反馈和浏览器兼容性。

## 灰度范围

- 继续使用 Web/H5 MVP，不迁移 Next.js，不做小程序。
- 继续只使用 A/B 且审核通过的卡牌候选。
- 分享海报、后台管理和真实服务端埋点仍为后续功能；本阶段只保留方案口径。
- 匿名事件不得上传原始图片、视频或人脸模板，也不得包含身份标识。
- 灰度期间默认不上传原始图片、视频或人脸模板。

## 建议指标

- 完成率：从入口到结果页完成，目标不低于 70%。
- 手动抽卡完成率：拒绝摄像头后仍能完成，目标 100% 可达。
- 动作成功率：明亮环境下目标不低于 90%。
- 分享率：后续海报能力上线后目标不低于 10%。
- 负面反馈率：风险文案投诉目标为 0。
- 摄像头关闭成功率：退出后停止 track，目标 100%。

## 匿名事件草案

`AnonymousMvpEvent v0.1` 只允许记录：

- `event_type`
- `session_step`
- `trigger`
- `card_group`
- `fallback_reason`
- `timestamp`

禁止记录：原始图片、视频、关键点数组、人脸模板、用户 ID、手机号、设备指纹、身份识别结果。

## 失败路径

灰度前必须覆盖以下兜底路径：

- `camera_denied`
- `model_error`
- `no_face`
- `multi_face`
- `low_light`
- `off_center`
- `action_timeout`
- `no_card_candidate`

每条路径都必须展示明确提示，并提供手动抽卡入口。

## Go/No-Go 建议

满足以下条件即可进入 Phase 5：

- `npm run validate:phase4` 通过。
- 桌面 Chrome 和移动端浏览器手动抽卡闭环无控制台错误。
- 结果页含出处、现代释义、行动建议和免责声明。
- 内容安全复核报告无阻断项。
