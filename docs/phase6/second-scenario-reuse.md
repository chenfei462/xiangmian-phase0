# 第二场景复用说明

Phase 6 的交付目标是把前程镜复制到第二个活动场景。推荐第二场景为“山河镜”，适合文旅、城市展陈和国风市集。

## 可复用模块

- `ThemePack`：替换主题名、定位、允许卡组、结果模板、海报模板和免责声明策略。
- `CampaignConfig`：替换活动 ID、发布时间、卡池、反馈入口、指标门槛和发布状态。
- 端侧视觉流程：继续复用摄像头授权、校准、动作触发、手动兜底和退出清理。
- 内容护栏：继续禁止命运定论、健康寿命、婚恋刑克、财富预测、职业成败和敏感属性推断。

## 山河镜差异

- 主题重点从毕业/求职行动建议切换为城市漫游、空间观察、路线拆解和展陈打卡。
- 卡组优先使用“山河五岳”“三停流转”“神气心相”。
- 海报使用山水纹样、城市二维码和非人脸主题视觉。
- 运营指标沿用完成率、手动兜底率、动作成功率、海报生成率、分享点击率和负面反馈数。
