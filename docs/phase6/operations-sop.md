# 第6阶段运营 SOP

## 发布前

- 确认活动主题为前程镜，活动定位为传统文化娱乐互动。
- 确认法务复核通过摄像头授权、结果页免责声明、分享海报免责声明和反馈入口文案。
- 确认发布构建通过 `npm test`、`npm run validate:phase6`、`npm run typecheck` 和 `npm run build`。
- 确认运营后台 v0.1 只展示活动配置、发布门禁、卡牌下线、指标摘要和演练记录。

## 发布中

- 每日查看完成率、动作成功率、手动兜底率、海报生成率、分享点击率和负面反馈数。
- 任何用户反馈命中文案冒犯、隐私误解、健康/命运/财富预测风险时，立即执行卡牌下线。
- 匿名事件只允许记录活动、流程步骤、动作类型、卡牌类别、失败原因、时间桶和时间戳；不上传原始图片、视频或人脸模板。

## 卡牌下线

1. 将命中的 `card_id` 加入 `CardBlocklist`。
2. 记录原因、审核角色、时间和备注。
3. 复测结果页与海报，确认该卡牌不再出现。
4. 若候选不足，使用安全兜底卡或手动抽卡流程。

## 回滚

- 隐私或法务风险：立即暂停活动入口，回滚到 Phase 5 灰度版本。
- 内容安全风险：下线卡牌并暂停该主题包，回到第4阶段内容复核。
- 摄像头兼容性风险：保留手动抽卡入口，关闭默认开镜提示。
