# 第1阶段内容 QA 报告

## 数量

- 术语条目：360。
- 卡牌草稿：315。
- 来源记录：12。
- 发布候选：不少于 300。

## 安全门禁

- C/D 条目不得出现在可发布卡牌候选集中。
- 可发布文案不得包含疾病、寿命、怀孕、生育、刑克、贵贱等禁用断语。
- 每条术语必须有来源、短摘录、现代释义、风险等级和审核状态。

## 验证命令

```bash
npm test
npm run validate:knowledge
npm run typecheck
npm run build
```

## 交接结论

第1阶段交付的是本地结构化知识库和检索/导出工具。第2阶段可使用动作触发候选集验证视觉原型；第3阶段可把 `CardDraft` 和导出的 `CardRule` 接入 MVP 规则引擎。
