# 第7阶段商业化交付包

## 文旅客户演示话术

山河镜适合城市展陈、文旅空间和国风市集，用摄像头动作或手动抽卡触发传统文化卡牌。用户获得城市漫游、空间观察和展陈打卡建议，并生成不含原始人脸的主题海报。

## 品牌联名禁区

- 不承诺转化、好运、财富、职业结果或城市运势。
- 不评价地域优劣、人群标签、外貌高低或身份属性。
- 不要求上传原始人脸图像，不把用户照片作为训练数据。
- 不用“AI 算命”“预测准确”“命定”等表达。

## Phase 8 建议

- 将本地多主题注册表迁移为正式后台配置模型。
- 评估账号权限、审核流、活动版本、卡牌上下线和只读数据看板。
- 若进入线下展陈硬件化，再单独评估打印机、NFC、大屏、设备巡检和现场网络方案。
- Phase 8 仍应保留端侧处理、手动兜底、免责声明和卡牌下线开关。
